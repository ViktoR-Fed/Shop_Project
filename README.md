# Проект - Онлайн магазин (начало)

## Начало проекта по созданию онлайн магазина.

## Функционал проекта.

### Модуль category
    Модуль представляет из себя класс по инициализации категорий продуктов:

**__init__(self, name, description, products):**

    Получает наименование, описание и список продуктов в категории

### Модуль base_product
    Модуль представляет из себя абстрактный класс по инициализации продуктов

### Модуль print_mixin
    Класс, расширяющий функционал основных классов, посредством вывода соответствующего сообщения
    при инициализации нового объекта этих классов.

### Модуль product
    Модуль представляет из себя класс по инициализации продуктов:

**__init__(self, name, description, price, quantity):**

    Получает наименование, описание, цену и количество продуктов

### Модуль smartphone
    Модуль представляет из себя дочерний класс по инициализации продуктов (смартфонов):

**__init__(self, name, description, price, quantity, efficiency, model, memory, color)**

### Модуль lawn_grass
    Модуль представляет из себя дочерний класс по инициализации продуктов (газонной травы):

**__init__(self, name, description, price, quantity, country, germination_period, color)**

### Модуль utils
    Модуль предоставляет функции для чтения и создания объектов из JSON-файла.

**read_json(path: str) -> dict**
Функция для чтения JSON-файла.

**Параметры:**

#### path: Путь до JSON-файла

**Пример использования:**
```
data = read_json("../data/products.json")
```

Функция для создания объектов из полученных данных
